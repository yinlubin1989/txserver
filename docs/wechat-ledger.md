## 2. 为什么清缓存后账单会消失

旧版账单在数据库中，但所属账本使用本地随机凭证识别。清理小程序缓存后，凭证消失，客户端失去原账本的访问关联；不是服务端自动删除了账单。

新版调用微信原生 `wx.login` 获取一次性 code，服务端向微信验证身份。用户无需填写账号密码，不读取昵称、头像或手机号。账单按已验证的微信身份隔离，同一微信、同一小程序清缓存或换手机后可读取已关联账本。

## 3. 旧账单迁移

1. 先在服务器配置 AppID/AppSecret，部署新版接口。
2. 在仍能看到旧账单的设备上更新小程序。
3. 使用希望关联账本的微信，打开一次“我的记事本”，等待列表成功加载。
4. 新版会将原设备账本关联到当前微信；保留账单 ID、金额、分享链接、私有/公开状态。
5. 关联成功后，同一微信重新打开、清缓存或换设备都能访问该账本。

迁移完成前，不要清除仍保留旧账单凭证的设备缓存。若旧凭证已全部丢失，不能凭分享链接、金额或 IP 自动认领；需另行核实归属。

## 4. 微信登录接口

`POST /api/finance-ledger/wechat-session`

请求体：

```json
{ "code": "由 wx.login 返回的一次性 code" }
```

首次关联旧设备账本时，在 Authorization 中携带原设备凭证：`Bearer <旧凭证>`。没有旧账本时不传。

成功：HTTP 201。

```json
{
  "schemaVersion": 1,
  "status": "completed",
  "session": {
    "token": "64 位随机会话凭证",
    "identity": "wechat",
    "expiresAt": "2026-12-11T00:00:00.000Z"
  }
}
```

后续账本请求使用新 token。会话有效期为 30 天；小程序只在当前运行期间缓存会话，冷启动重新获取。微信身份本身保持关联。身份数据仅由微信服务端验证，不接受客户端自报 OpenID。

失败统一返回 `status: "failed"`、`code`、`error`，不会伪装成空账本：

| 错误码 | 含义 |
| --- | --- |
| WECHAT_NOT_CONFIGURED | 服务端缺少 AppID/AppSecret |
| WECHAT_CODE_INVALID | 一次性 code 已失效，重新登录 |
| WECHAT_LOGIN_UNAVAILABLE | 微信调用失败、配置错误或响应异常 |
| LEGACY_SESSION_CONFLICT | 原凭证无效或已关联其他微信 |
| UNAUTHORIZED | 账本会话无效或到期，可重新微信登录后重试一次 |

## 5. 公开与私有

- “我的记事本”只显示自己的账单，没有全站公开账单广场。
- 公开账单：拿到分享链接的人可查看对应统计结果，不可编辑，不可查看账本其他内容或原文全文。
- 私有账单：仅所属用户可查看；改为私有会撤销原分享链接。
- 删除账单后，列表和分享均不可访问；清缓存不会恢复已删除账单。
