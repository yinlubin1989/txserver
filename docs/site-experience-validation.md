# 全站体验优化验收

日期：2026-09-10。分支：`codex/site-experience-polish`。

## 范围与交付

保留极简风格，电脑优先兼顾手机。调整首页、记账、相册、两种上传、书架、原则、RGS 文档与密笺；未更改小游戏、外部服务、加密实现或部署配置。

功能缺陷先以 `cdce5b5` 独立提交：相册按现有 `{ photos: [{ name, mtime }] }` 响应构造图片地址；上传表单在异步操作前保存稳定引用。上传缺陷已在修改前用模拟响应复现“上传成功”和“网络异常，上传失败”同时出现。

视觉调整保留全部首页链接、书籍与原则正文、文档锚点、安装包与 Markdown 下载地址。密笺业务函数及 `secret-crypto.ts` 未改。记账价格、存储键 `txserver-calc-daily-v2`、同日多条记录、长按清项、声音与震动逻辑保留。

## 验证方法

- 浏览器：隔离的 Chromium 会话，开发站点 `http://localhost:8000`；生产构建在 `http://localhost:8001` 检查 CSS 与截图。
- 视口：1440、1024、820、390、320px。缩放使用 720×500 CSS 视口、DPR 2，验证 1440×1000 桌面在 200% 下的等效重排；这不是原生浏览器缩放快捷键测试。首页另做 CSS `zoom: 2` 压力检查。
- 记账仅使用隔离会话的本地存储。照片和上传使用临时图片与浏览器模拟 API，未向线上提交上传或删除请求。
- 界面事件通过浏览器控件或原生 DOM 事件触发；所有断言读取真实页面结果，不根据源代码推断通过。

## 已完成检查

- 首页：所有原入口保留，分组为工具、内容、服务；所有链接点击区域至少 44px；窄屏与等效缩放无横向溢出，页脚随文档流排列。
- 记账：20 项行为断言通过，包括旧 v2 数据读取、六位输入上限、四种单价正负计算、空输入按 1 添加、退格、C 与本笔清零、长按 500ms 清项及抑制后续点击、同日多次保存、刷新持久化、本月统计、存储失败保留输入，以及单条删除、取消／确认清空全部记录。大额 `¥367,999,632` 完整显示；操作按钮至少 44×44px。
- 书架与阅读：书架桌面三列／手机两列，原则正文保持一致；RGS 目录可通过 Enter 展开，点击原锚点后 hash 与目标标题对应，正确滚动到标题。
- 密笺：中文与 emoji 加解密往返一致，自动带入密文、错误口令提示正确；清空仅清除当前模式的输入和结果并保留口令，生成随机口令为 24 位。原生复制有成功反馈；另以 Clipboard API 测试替身验证密文与口令载荷准确，未读取系统剪贴板内容。
- 相册：元数据正确映射为文件名 URL，原图实际解码成功；加载中、空列表、字符串数组／null 等错误响应和网络异常有独立提示。大图初始焦点在关闭按钮，Tab／Shift+Tab 在弹层内循环，Esc 与取消删除恢复原缩略图焦点；错误密码不删除，正确密码删除后聚焦照片列表，删除最后一张后显示空状态并保持焦点。
- 上传：两种流程均保持 `image` 字段和各自接口；通用上传成功只显示成功、清空文件框并增加记录，失败保留文件且不显示成功。相册上传失败留在上传页，成功回到相册。已验证旧历史 GET 晚于 POST 返回时新记录仍保留；按接口 `id` 去重，避免新记录被旧快照覆盖。
- 全部 9 个页面在五种目标宽度与 200% 等效视口下无页面横向溢出；记账和通用上传在 ≥1024px 双栏，密笺 <941px 的输入、口令、结果保持顺序。

## 工程检查

- `npm run build`：通过。最终执行需允许 Turbopack 的本地内部端口；沙箱内的一次尝试被 `EPERM` 阻止，放行后重跑通过。
- `node node_modules/typescript/bin/tsc --noEmit --incremental false`：通过。
- 本轮改动范围 ESLint 与 `git diff --check`：通过。
- 全量 `npm run lint`：修改前已存在 4 个 `react-hooks/set-state-in-effect` 错误，位于 `AuthModal.tsx`（2 个）、`TimeEntryModal.tsx`、`TodoApp.tsx`；这些未接入本轮页面的旧组件未作调整。
